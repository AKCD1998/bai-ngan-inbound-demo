# ใบงาน

ต้นแบบติดตามเอกสารสำหรับทีม · สีพาสเทล · ปุ่มง่าย

**เปิดใช้งาน:** https://akcd1998.github.io/bai-ngan-inbound-demo/

- ดูรายการหรือบอร์ด แก้ไขเอกสาร เพิ่มบันทึก และส่งต่องาน
- ข้อมูลตั้งต้นเป็นข้อมูลสมมติทั้งหมด ไม่มีเอกสารบริษัทต้นฉบับใน repository
- ข้อมูลที่กรอกและไฟล์แนบเก็บในเบราว์เซอร์ของแต่ละคน ไม่ส่งขึ้น GitHub
- สำรอง/นำเข้า JSON ได้เฉพาะข้อมูลรายการ ไม่รวมไฟล์แนบ
- ยังไม่เชื่อม OCR, ERP หรือฐานข้อมูลร่วมกัน การเปลี่ยนสถานะไม่ใช่การยืนยันความถูกต้องของ OCR

เปิด `index.html` หรือใช้ GitHub Pages จาก branch `main` / root ได้เลย ไม่ต้องติดตั้งแพ็กเกจ
